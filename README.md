# ❤️ Icono Vectorial SVG de Corazón en HTML

Este repositorio contiene un ejemplo sencillo y ligero que demuestra cómo renderizar e integrar gráficos vectoriales escalables (SVG) directamente en un documento HTML utilizando la etiqueta `<svg>` y trazados con `<path>`.

---

## 🚀 Características

* **Gráficos Vectoriales Integrados:** Implementación de SVG de forma nativa (*inline SVG*) sin necesidad de librerías externas.
* **Diseño Escalable:** Mantiene la resolución y nitidez en cualquier tamaño de pantalla sin perder calidad.
* **Código Ligero:** Estructura HTML5 reducida al mínimo para pruebas, prototipos o inclusión en componentes UI.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5**
* **SVG (Scalable Vector Graphics)**
